## リッチテキスト表示

ウインドウ内で、複数の文字スタイルと行揃えを組み合わせられるリッチテキスト表示機能を追加します。

実装仕様と進捗: [RICH_TEXT_PLAN.md](RICH_TEXT_PLAN.md)

### 必須機能

- [x] 文字単位でフォントを指定できる。
- [x] 文字単位でフォントサイズを指定できる。
- [x] 左寄せで表示できる。
- [x] センター寄せで表示できる。
- [x] 右寄せで表示できる。

### 必須の受け入れ条件

2026-08-31 完了。`bun run check` 緑。公開仕様は `SPECIFICATION.md` / `API.md`。

- [x] 1つのリッチテキスト内で、文字ごと、または任意の文字範囲ごとに異なるフォントとフォントサイズを混在できる。
- [x] フォント指定とフォントサイズ指定を同じ文字範囲へ同時に適用できる。
- [x] 左寄せ、センター寄せ、右寄せは、利用可能な content 幅を基準に配置される。
- [x] 複数行でも各行の実測幅を基準に、指定した行揃えが正しく適用される。
- [x] 異なるフォントサイズが同じ行に含まれても、文字が不自然に上下へずれないよう共通のベースライン規則で配置される。
