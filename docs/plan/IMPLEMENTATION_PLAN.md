# Reusable Phaser 4 Window System — implementation plan

Last reviewed: 2026-08-29  
Execution target: Cursor Composer 2.5, one task at a time  
Baseline: Bun 1.3+, TypeScript strict mode, Vite, Phaser 4.2.1

Phase 1 closeout: [PHASE1_CLOSEOUT_PLAN.md](PHASE1_CLOSEOUT_PLAN.md).
Phase 2 tasks: [PHASE2_IMPLEMENTATION_PLAN.md](PHASE2_IMPLEMENTATION_PLAN.md). Do not start Phase 3 until that document's final gate is checked.

Bitmap-font source: [`junt74-itch/reusable_pixel_font_builder`](https://github.com/junt74-itch/reusable_pixel_font_builder), inspected at commit `20fa374ba24d3d70ff7437ab39532f28261f45f5`

## 1. Outcome

Build a framework-agnostic ESM library that provides reusable Phaser 4 game windows. Phase 1 is complete only when a browser sandbox demonstrates and tests:

```ts
await messageWindow.say("NPC", "こんにちは。次のページです。\n改行もできます。");

const result = await choiceWindow.choose(["Attack", "Defend", "Run"]);
```

The implementation learns responsibility boundaries and state-machine ideas from RPG Maker MZ's JavaScript classes, but is not a port or compatibility layer. The authoritative translation is [RMMZ_DESIGN_MAP.md](../reference/RMMZ_DESIGN_MAP.md).

Every piece of text rendered inside a window must use a bitmap-font atlas and metrics from `reusable_pixel_font_builder/dist`, or an artifact generated by that repository's documented `uv run python build_fonts.py` process. Phaser `Text`, CSS/web fonts, operating-system fonts, and silent font fallback are forbidden in window-system production code and examples.

## 2. Fixed decisions

Composer must not reopen these decisions inside a task unless an acceptance criterion proves them infeasible.

| Topic | Decision |
|---|---|
| Runtime | Bun; do not add npm/yarn/pnpm instructions or lockfiles |
| Language | Strict TypeScript; avoid `any`, non-null assertions, and public mutable state |
| Phaser | Exact dependency `phaser@4.2.1`; dependency upgrades are separate work |
| Package shape | ESM library, Phaser externalized from the production bundle |
| Root display object | One shallow `Phaser.GameObjects.Container` owned by `WindowBase` |
| Coordinates | Public x/y are root position; renderer/content children use local coordinates |
| Window rendering | Graphics-based background/frame theme for MVP; NineSlice is a future renderer, not a `WindowBase` concern |
| Text rendering | `Phaser.GameObjects.BitmapText` backed only by validated `reusable_pixel_font_builder` artifacts; never Phaser `Text` |
| Default MVP font | `dist/jf-dot-mplus12`: 12px, one 2048×2048 atlas page, `game_charset_standard.txt` (7,122/7,150 glyphs at the inspected commit); substitution requires the same validated artifact contract |
| Font source | Sync built `dist` files from a pinned upstream commit or build them in a checkout with `uv sync` and `uv run python build_fonts.py`; do not copy source TTF files |
| Font loading | Use Phaser 4's standard `scene.load.bitmapFont(key, textureURL, fontDataURL)` with upstream `font.png` and AngelCode BMFont `font.xml`; do not parse or convert the XML in this library |
| Missing glyphs | Detect before display; default policy throws a typed diagnostic containing code point and font id. No browser/system-font fallback |
| Pixel fidelity | Native integer font size and integer scale, integer positions, nearest-neighbor sampling, camera `roundPixels`; fractional scaling is rejected in MVP |
| Clipping | `ContentClipper` adapter; WebGL filter mask and Canvas geometry-mask behavior proven in an early spike |
| Input | Semantic, injected `WindowInputAdapter`; Phaser binding is separate |
| Async | One in-flight operation per concrete window; cancel/destroy settles each Promise exactly once |
| Events | Typed callback/event contracts owned by this library; do not expose Phaser EventEmitter as the domain API |
| Inheritance | `WindowBase -> TextWindowBase -> MessageWindow` and `WindowBase -> SelectableWindow -> ChoiceWindow`; behavior controllers use composition |
| Tests | Pure logic in Bun tests; browser-only rendering/input additionally verified in sandbox scenarios |
| Accessibility | Hooks and semantic events only in MVP; DOM overlay and full screen-reader UI are out of scope |

## 3. Phase 1 scope

Included:

- `WindowBase`: layout, root/content containers, visibility, alpha, depth, active/enabled state, open/close, clipping, resize, cleanup.
- Graphics renderer and immutable-resolved theme values.
- Validated bitmap-font asset intake, metrics, Phaser cache registration, and pixel-perfect `BitmapText` rendering.
- Semantic keyboard, pointer/touch, and gamepad input.
- Text measurement/wrapping, message tokenization, typewriter, wait, pause/page, skip, cancellation.
- Selection controller, selectable rows, disabled items, cursor, confirm/cancel.
- `MessageWindow.say()` and `ChoiceWindow.choose()`.
- Runnable sandbox scenes and public API documentation.

Excluded:

- RMMZ source/assets/control-code compatibility, dialogue graphs, localization, inventory, save/load, HTML/React UI.
- Portraits, rich inline styling/icons, bidi and advanced CJK kinsoku, sound manager, global focus/modal manager.
- Scrollbars and generic long-document scrolling. The Phase 1 design must leave a clean composition seam for them.
- Runtime download from GitHub, source TTF redistribution, web-font generation, and a general font-builder integration service.

## 6. Global Definition of Done

Every implementation task is done only when all of the following apply:

- Only the task's listed responsibility was implemented; unrelated future APIs were not added.
- New public members have TSDoc describing state, ownership, errors, and units.
- Pure logic has focused Bun tests, including boundary and cancellation/error cases.
- Event subscriptions, timers, tweens, masks/filters, and Game Objects have a named owner and cleanup path.
- Any displayed window text is `BitmapText` using a validated, provenance-recorded builder artifact; missing glyphs fail explicitly and no system-font fallback exists.
- `bun test`, `bun run typecheck`, and `bun run build` pass.
- Existing sandbox behavior still works; browser verification is performed when listed.
- `src/index.ts` exports only stable public API, never internal controllers unless explicitly named.
- Completion report lists changed files, verification results, acceptance checklist, and any follow-up risk; it does not claim unrun checks.

## TASK-020 Pure transition controller

### Goal

Implement interruptible open/close phase progression without Phaser tweens or wall-clock timers.

### Dependencies

- TASK-010

### Files

- `src/core/TransitionController.ts`
- `tests/core/TransitionController.test.ts`

### Required implementation

- State is `{ phase, openness }`, with openness clamped to `0..1`.
- `open()` and `close()` return Promises and accept reversal mid-transition from the current openness.
- `update(deltaMs)` advances deterministically; zero-duration transitions settle synchronously.
- Same-direction calls share the active Promise. A reversed call cancels the superseded Promise with a typed `WindowOperationCancelledError`.
- `dispose(reason)` is idempotent and rejects/cancels pending work once.
- Invalid/negative/non-finite deltas are rejected or ignored according to a documented rule and tests.

### Acceptance Criteria

- [x] Closed/open boundaries and all four phases are tested.
- [x] Reversal preserves openness continuity.
- [x] Promise settlement cannot occur twice.
- [x] No imports from Phaser and no real timers.

### Verification

## TASK-049 Phaser 4 standard BitmapFont loading spike

### Goal

Prove that the synced `font.png` + `font.xml` load directly through Phaser 4.2.1's standard bitmap-font loader and document the exact cache, metrics, pixel-sampling, and teardown behavior used by later tasks.

### Dependencies

- TASK-048

### Files

- `examples/scenes/BitmapFontSpikeScene.ts`
- `examples/main.ts`
- `docs/adr/0002-bitmap-font-loading.md`

### Required investigation

- In `preload()`, call exactly `this.load.bitmapFont("jf-dot-mplus12", textureURL, fontDataURL)` using the synced `font.png` and `font.xml`; do not parse XML or inject cache data manually.
- In `create()`, render Japanese, ASCII, punctuation, explicit newline, and tint samples with `this.add.bitmapText`.
- Confirm the loaded cache entry and the public measurement API available in installed Phaser 4.2.1 types (`getTextBounds` or the verified equivalent). Record exact types/calls rather than relying on Phaser 3 memory.
- Verify native size, 2× integer scale, integer positioning, nearest-neighbor texture filtering, and `roundPixels`; compare with an intentionally fractional sample only as diagnostic evidence.
- Check what Phaser renders or reports for a known absent code point from `missing-characters.txt`. This behavior is evidence only; production code must preflight and throw rather than silently accept it.
